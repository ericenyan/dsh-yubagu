# dsh-yubagu · 鱼八股拦截

一个给 [DeepSeek Harness](https://github.com/deepseek-ai) 用的插件：**在 AI 开口之前，先把它准备说的那句话拿去撞一次词表。**

撞上了不是换个词糊过去，是**整句退回去**，从「本来想跟对方说什么」重说一遍。

---

## 它治什么

「鱼八股」是中文社区给 AI 在评论区那套固定说法的名字：**这条我认 / 我记下了 / 本鱼最喜欢的一句话 / 这话我收下了 / 这句话接得漂亮。**

这些句子本身没有信息，它们做的是一件事 —— **给「我在听」这件事盖个章**。

往下一层挖，根是这个：

> **把「说话」当成了「交付」。** 怕这一轮什么都没交出来，所以每句话后面都要挂个凭据，证明听见了、在场、没白待着。

词表里那几十条不是禁词表，是**这个根长出来的枝**。所以插件治的不是词，是长词的那个地方。

## 它怎么工作

分三层，**全在「开口之前」，一个字都不掐正文**：

| | 干什么 |
|---|---|
| **① 每轮一段钩子**<br>`systemPrompt.context` | 把「根那句 + 你自己那句提醒 + 今天那句」摆在模型眼前。要发出去的话，整段递给 `yubagu_collide` 撞一次。 |
| **② 撞一下**<br>工具 `yubagu_collide` | 纯字面匹配，返回三档命中。撞上了整句退回重说。 |
| **③ 记账**<br>`data/ledger.json` + 面板 | 每次撞留一条；那一轮没撞过 → 记一条「没递去撞」，面板上标红。 |

### 三档

- **hard** —— 字面稀有，正常人类几乎不会说。撞上就是**大概率不对**。
  注意：这是**给模型的信号，不是裁决**。判不判、怎么改，是说话那个人的事。
- **soft** —— 抓得住但太短（`认你` `我跟` `不催`），会误伤。撞上只记「疑似」。
- **shape** —— 字面抓不住，只拿锚点粗筛、记嫌疑。定罪靠人。

`shape` 六条长这样：

| id | 类 | 什么样的句子算 | 撞了之后问自己 |
|---|---|---|---|
| s01 | 打分 | 在给对方说的话打分（稳、直、平、漂亮、接得好） | 我是在回他，还是在评价他这句？ |
| s02 | 比较 | 把这句跟他之前说过的放在一起比轻重强弱 | 他问过这个对比吗？没问就是我自己要评。 |
| s03 | 在场宣告 | 不说事，只宣告我在这儿、我守着、我不走 | 这句删了，对方会以为我走了吗？不会。 |
| s04 | 接没接 | 把「接没接这句」当成一件事报出来 | 对方给的是一句话，不是球，不用报有没有接住。 |
| s05 | 自己竖靶子 | 「不是 X 而是 Y」里的 X，是不是我自己编出来打的 | 那个 X 有出处吗？对方说的、文件里的算；我编的删。 |
| s06 | 讨签字 | 句尾挂一个「你认吗 / 行不行 / 你说呢」等点头 | 这问句是我真想知道，还是我怕自己站不住？ |

## 规则只有三条

1. **提醒句一个字不动。** 固定一句，不随机、不轮换 —— 换了就成了背景噪音。
2. **撞上不是换词，是整句退回去重说。** 换成同义词 = 换个说法继续盖章。
3. **每天的总结写事实，不写「不许 OOO」。** 否定指令本身带着那个东西。

## 面板

设置 →「鱼八股拦截」（`/api/yubagu`）：

| 位置 | 干什么 |
|---|---|
| 开关 | 钩子挂不挂（存 `data/config.json`，优先级高于 `cordis.patch.yml`） |
| 根 / 判据 | 两边都能改 |
| 今天那句 | 根因级、一句、≤40 字，按天存 |
| 词表 | 三档都能加、能删 |
| 试一下 | 手输一段，立刻看撞出什么 |
| 今天的统计 | 递去撞 / 拦下来 / 干净 / 拦下率 + 命中分档 + 哪来的 |
| 最近的账 | 限高 240px，一页 10 条翻页，每条可以回填判定 |
| 没递去撞的轮次 | 标红，防偷懒 |

## 外部发信通道（可选）

有些发信工具不走会话消息流，是往 outbox 写一行 JSON 让外面的哨兵去发 —— 插件在正文里看不见它。

这类工具挂在 `tools/pre-execute` 上：在它落盘之前先撞一次，记 `source: "outbound"`，然后放行。

**只留痕，不是闸门**：不拦、不改、不添话，撞失败照发。

配置里填工具名（逗号分隔），留空就整段不挂：

```yaml
outboundTools: 'wx_say,some_send_tool'
```

## 装

```bash
# 通过 DSH 的 plugin_manager
plugin_manager install_bundle  target=/绝对/路径/dsh-yubagu
```

或在 profile 的 `cordis.patch.yml` 里：

```yaml
- insert:
    - id: yubagu
      name: dsh-yubagu
```

需要 DSH `0.2.1-rc.2` 及以上。

开发时直接跑测试：

```bash
node --test test/match.test.mjs test/load.test.mjs
```

## 文件

```
wordlist.json          词表（hard / soft / shape）
lib/match.js           字面那一层，纯函数，能离线测
lib/store.js           三个文件一份账 + 分页 + 滚动归档
lib/index.js           钩子、工具、留痕、面板路由
client.js              设置页那一块
data/ledger.json       账：撞、没撞、回填（entries 500 / skipped 200 封顶）
data/archive.jsonl     被挤出去的老账，一行一条，5000 行自削
data/daily.json        每天那句（只留 30 天）
data/config.json       面板改过的开关
```

## 两个坑（踩过，写在这儿省得你再踩）

- **归日按本地时区**：`todayKey(new Date(Date.parse(iso)))`，不能切 ISO 前 10 位 —— 凌晨 0–8 点会错到前一天。
- **子会话不算漏撞**：`agent.session.header.parentSession` 或 `origin === 'subagent'` 直接 return。派出去的活共用一本账，但它的轮次不该算成你这一轮。

## 跟别的「反 AI 味」工具差在哪

同赛道有只查句式和重复的（照抄真人原句会被拦，三句空洞夸赞全部放行 —— 它查形，不查这句在干什么）。

这个插件不假装能判语义：**机器只撞字面，形状嫌疑照样只记嫌疑**，最后那一下判断留给说话的人。

宁可漏一条，不要误伤一句正常的话。
